# non

*Non* refers to one or more of the following, or all in combination with each other:

- the **Non machine**, a [reversible computer](https://en.wikipedia.org/wiki/Reversible_computing) implemented as a [streaming language rewrite processor](https://awelonblue.wordpress.com/2019/02/22/streaming-language-rewrite-processing/), which only exists in VM form for now
- the **Non programming system**, a declarative, reversible [term rewriting system](https://en.wikipedia.org/wiki/Rewriting#Term_rewriting_systems) used via REPL
- the **Non protocol**, a network protocol for linking Non systems into a distributed computing grid

This project is in pre-pre-pre-pre-alpha stage.
